# Portfolio Personal

Portfolio personal desarrollado con React, TypeScript y Vite, creado para presentar mis proyectos de desarrollo web, mi perfil profesional y mis formas de contacto.

## Tecnologías

- React
- TypeScript
- Vite
- Tailwind CSS
- Git
- GitHub

## Características

- Diseño responsive
- Sección de presentación personal
- Galería de proyectos
- Enlaces a repositorios y demos
- Acceso a CV
- Sección de contacto

## Objetivo

El objetivo de este proyecto es construir una presencia profesional online y mostrar mi evolución como desarrolladora web junior.
